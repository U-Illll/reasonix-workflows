# 探索任务书模板（Standard_Mode_Two / templates，E 相位专用，v1.1）

> E1 节点分派专用（每维度一个探索任务书）。**派发前置四条件**：只读 + 死状态 + 证据锚定 + 出口组合可用（不满足即不派）。
> 派发对象：D5 探索群（deepseek 网页号池文本探索 / 内置 subagent 工具型探索）。
> 纪律：只读动作；不写文件、不发请求、不碰登录与风控面；适用「易漂移源接入规范」（隔离子代理 + 输出转义 + 崩即隔离，阶段 B 固化）。

## 通用骨架

```
Explore-Task: <ET-N> | Campaign: <战例> | Domain: explore | Mode: X1 | node_id: e-<缩写>-<NN> | parent: <父 node_id | root>
出口组合: <exit_ref，例 exit-03（IP 出口+账号）；一节点一组合，不得复用>
假设: <本节点要验证的一句话假设>
已知（继承边界，只给这三样）:
- 探索地图（E0）摘要: <≤120 字>
- 父卡摘要: <≤80 字>
- 公共已知: <反证/死路清单要点>
第1步: <只读动作1：工具/方法 + 对象 + 目的>
第2步: <只读动作2 ...>
只做这N步,不绕圈；不写文件、不发请求、不碰登录/风控面。
约束: 只读;死状态;证据锚定(每个结论带可复现证据指针);预算 max_steps=<N>;探索卡事实段 ≤500 字
回报格式: 探索卡事实段（explore-card.md ①）: node_id/parent/假设/已试动作/结果/证据指针/候选子女方向/exit_ref/side_effects
```

## X1 单节点多候选示例（一个目标多个假设并行验证）

```
[Explore-Task ET-3 | Campaign web | Domain: explore | Mode: X1 | node_id: e-web-03 | parent: root]
出口组合: exit-02
假设: 隐藏端点全部收敛在 /api/v2/ 路径族下

- 父卡摘要: root 侦察发现 3 组候选前缀（/api/, /v2/, /internal/）
- 公共已知: /internal/ 族已排除（404 全灭，死路 e-web-02）

第2步: <被动数据分析：已有抓包中出现的 /api/v2/ 请求> <目的：确认调用形态>
只做这2步,不绕圈；不写文件、不发请求。
约束: 只读;死状态;证据锚定;预算 max_steps=12;探索卡 ≤500 字
回报格式: 探索卡事实段（explore-card.md ①）
```
