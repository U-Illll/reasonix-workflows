# 探索卡模板（Standard_Mode_Two / templates，E 相位专用，v1.1）

> 每个探索节点终止时产出本卡（长节点加里程碑即时写，防中途崩丢）。**双段式**：①结构化事实段由探索 agent 写（≤500 字硬限）；②裁决摘要由指挥官 A 写（≤100 字）。
> 卡间不共享上下文（隔离）；子节点只继承「探索地图 + 父卡摘要 + 公共已知」。**死路卡是最高价值产出**——只留三件套，过程上下文丢弃。
> 落盘：`explore/<campaign>/<node_id>.md`（S1.5 档案）；节点树 ledger（JSONL 单调追加）登记 `node_id, parent, status, card_path, ts`；旧节点只读。
> 纪律：本卡同样过回执五关（净化解/漂移关）；证据锚定是进 S1.5/讨论层的**前置门**；卡内禁贴敏感原文（引用走 `vault:<ref>` 句柄或 artifact 路径）。

---

## ① 结构化事实段（探索 agent 写，≤500 字硬限）

```yaml
node_id: e-<战例缩写>-<序号>        # 例：e-web-07
parent: <父 node_id | root>
domain: explore
假设: <本节点要验证的一句话假设>
已试动作:
  - <动作1：工具/方法 + 对象> → <结果摘要>
  - <动作2：...> → <...>
结果: 成功 | 死路 | 不确定
证据指针:
  - <artifact 路径 / 回执 round_id / 文件:行号 / 响应片段摘要（≤100 字）>
候选子女方向:
  - <子方向1 + 一句话理由>
  - <子方向2 + ...>
exit_ref: <出口组合登记号，例 exit-03>   # 一节点一组合，不得并发复用
side_effects: []                        # 探索节点恒为空（只读边界）；非空即违规
```

## ② 裁决摘要段（指挥官 A 写，≤100 字）

```
[S1.5 裁决] 采信 | 存疑 | 驳回 —— <一句话理由>；下一步：<并入方向X / 停止此分支 / 移交 C 相位>
```

---

## 死路卡（三件套速写，最高价值产出的专用形态）

```yaml
node_id: <...>
parent: <...>
结论: <被排除的假设/路径>
死因: <为什么排除（一句话，可复现的判据）>
证据指针: <证据位置>
```

---

## 使用纪律

- 未过回执五关（净化解/漂移关）的卡不入档。
- 证据锚定未过者不进 S1.5 / 讨论层 / S1（验证门铁律）。
- 深度 ≤2-3 层；节点预算与收益递减判定见 `mode-two-round` §6.5。
- 卡摘要行（供 E0 跨轮回填）：`<node_id> | <结果> | <结论一句话>`（卡索引表专用，另行维护）。
